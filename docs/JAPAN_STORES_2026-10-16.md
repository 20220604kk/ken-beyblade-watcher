# 日網新增 OCN／Nojima／日本玩具反斗城

三站使用既有「日本拍賣／日網」清單與通知分流，不加入日亞單品資料庫，不修改日亞監控、下單、目標或登入狀態。不是三站的自動下單功能。

## 策略與目前實站證據

| 官網 | 讀取方式 | 本次實站結果 |
| --- | --- | --- |
| OCN | 搜尋清單發現商品，最多兩條並行讀取商品 JSON-LD 的 JPY 價格與庫存 | 控制讀取重試整批成功：12 件、12 件明確可購，約 1.943 秒；先前整批曾逾時，單次成功不代表長期穩定 |
| Nojima | 僅接受明確官方 Product＋Offer 結構化資料；不以清單存在當作有貨 | 提供的搜尋網址 HTTP 403，瀏覽器讀取也未成功；解析器仍待實頁驗證 |
| 日本玩具反斗城 | 官方搜尋表單依序查 CX-20、BX-54、ベイブレード；保存已發現商品網址，搜尋消失時再直查正式商品頁 | 品牌頁有明確空 ItemList；搜尋頁出現安全驗證，尚未取得 CX-20／BX-54 的正式商品網址 |

玩具反斗城不猜商品網址。直接查商品頁的標準 Product／Offer 路徑已有離線驗證，但尚未取得目標實頁驗證。未取得官方庫存證據時不推播有貨。

## 失敗與基線規則

- 新站每輪至少間隔 60 秒，並非日亞 A 的 2 秒節奏。失敗逐步延長，最高 15 分鐘。
- HTTP 403／429／503、跳轉、驗證或空白頁保留既有基線，停止該輪；不切換網址或瀏覽器繞過驗證。
- 玩具反斗城僅在每個搜尋回覆有明確空 ItemList 時接受零件結果。搜尋消失本身不把已知商品標為售罄。
- OCN 整批商品核對未完成時不覆蓋基線；清單價格不視為庫存。
- Nojima 抽選／シークレット販売不當作一般可購商品。
- 首次建立基線不發通知；明確新品／補貨沿用既有日本網站去重與排除規則。

## 檔案

- `src/japan-stores.js`：三站分類、解析、HTTP 讀取、重點搜尋與已知商品直查。
- `src/japan-auctions.js`：接既有監控狀態、通知與失敗保留基線。
- `src/index.js`：一次性新增預設目標、單站最低週期與 UI 週期回報。
- `config.example.json`：公開網址範例，不含帳號資料。
- `test/japan-stores.test.js`：合成頁面離線回歸，不替代實站庫存驗證。

本次沒有為套用新站而重載服務，避免影響使用者要求保持獨立、不變動的日亞流程。程式與測試新增不等於正式服務已載入；部署後須另外核對控制台三站清單及各站最近成功掃描。

驗證：日網相關 45 項通過。全套第一輪購物網站測試檔發生一次失敗；該檔單獨重跑 74 項通過，再跑同樣預設並行的完整套件 912 項全部通過。未修改該既有測試來消除失敗；其偶發原因尚未確認。
