- 舊台灣售價模組直接讀被 Git 排除的 `data/reference/taiwan-msrp-catalog.json`，新機會 ENOENT。已提供去除私人來源路徑的 `assets/reference/` 作為預設，本機自訂版本仍優先；對應價格測試通過。

- 移除交接副本內無法獨立匯入的退役 Facebook drill；購物網站測試與主程式保留，家用檔案未刪。
- 一次完整執行曾出現隨機本機 port 被 Node fetch 判為 `bad port`；同檔針對重跑與最後完整重跑均通過。若公司重現，應查測試動態埠，不要把它當外站登入或結帳錯誤。
