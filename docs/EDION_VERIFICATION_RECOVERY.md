# 愛電王背景監控（連接器 1.1.0）

## 現在採用的方案

- 由普通 Chrome 在官方搜尋頁的來源內，背景 GET 最新商品 HTML，再解析公開商品資料。
- 不重整畫面、不切換焦點、不彈驗證視窗、不發送要求使用者按驗證的提醒。
- 這是 HTML 讀取，不是已找到商品 JSON API，也不是繞過官方驗證。
- 不提取或移植 Cookie／驗證憑證；只有瀏覽器正常的同來源請求。

## 排程與失敗處理

連接器每約 30 秒向本機取得排程；正常商品查詢最低間隔 5 分鐘。受限恢復後會降速：首次恢復最低 15 分鐘，24 小時內重複受限最低 30 分鐘。

403、429 或驗證頁：依次冷卻 15、30、60 分鐘，再背景重查。如果官方要求更長的 Retry-After，採用官方等待時間。逾時或內容不完整：依次等待 1、2、4、8、15 分鐘。冷卻期間不對官網送出新的查詢。

查不到、被擋、資料不完整，都保留原基線，不把庫存變成 0。控制台分開顯示「最新有效資料」及「最近背景嘗試」；連接成功不等於庫存已更新。舊版連接器不再取得讀取任務，顯示等待更新。

## 啟用

已安裝的連接器只需在 Chrome 擴充功能管理頁按一次「重新載入」，不需重新配對。Chrome 必須保持開啟；關閉或休眠會中斷／延後查詢。第一次需要一個不切到前景的官方搜尋分頁作為來源，之後不重整該分頁。
