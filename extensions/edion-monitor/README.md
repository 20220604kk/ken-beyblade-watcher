# 愛電王本機連接器

Chrome Manifest V3 擴充功能，把官方商品名稱、網址、價格與庫存觀測送到配對的本機監控儀表，不加車或下單。

## 安裝

1. 開啟 `chrome://extensions`，啟用開發人員模式。
2. 載入未封裝項目，選擇你下載位置的 `extensions/edion-monitor` 資料夾。
3. 本機控制台 → 日本拍賣 → 愛電王連接器，產生配對碼。
4. 在擴充功能視窗貼入配對碼，連接本機服務。

Chrome 需保持開啟；工具列沒圖示時可從擴充功能選單釘選。連接成功與官網商品可讀是不同狀態。

排程重整可能受 Chrome 休眠延後。遇到人機驗證會停止刷新並保留官方頁面，由使用者本人完成；不代解 CAPTCHA，也不匯出登入憑證。

控制台停用監控／連接器或離開監控時段時不派發商品讀取。配對碼是秘密，重新產生會撤銷舊配對。
