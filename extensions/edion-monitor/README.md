# 愛電王本機連接器

## 擴充功能不見時

連接器檔案仍保留在本專案。2026-10-10 專案由 `facebook-beyblade-watcher` 改名為 `beyblade-watcher`，舊的未封裝載入路徑已不存在。若 Chrome 找不到連接器，雙擊本資料夾的「安裝愛電王連接器.cmd」，依下面步驟載入新路徑，再配對；不要修改 Chrome 設定檔或刪除登入資料。

工具列未顯示圖示也可能只是未釘選，可先在 Chrome 的擴充功能選單尋找「陀螺監控・愛電王本機連接器」。本機顯示「Chrome 已連接」才代表橋接恢復；商品觀測正常才代表官網可讀。載入連接器並不等於解除 Cloudflare 驗證。

一次性安裝：

1. 在你平常使用的 Chrome 輸入 `chrome://extensions`。
2. 開啟「開發人員模式」，按「載入未封裝項目」。
3. 選擇 `D:\codex\beyblade-watcher\extensions\edion-monitor`。
4. 本機控制台 → 日本拍賣 → 愛電王普通 Chrome 連接器 →「產生／複製配對碼」。
5. 點 Chrome 工具列／擴充功能選單的「陀螺監控・愛電王本機連接器」，貼上配對碼，按「連接／恢復」。

之後：

- 自動建立一個不切到前景的專用搜尋分頁。Chrome 必須保持開啟。
- 正常最低每 60 秒重整一次；每約 30 秒向本機取得排程。Chrome 休眠可能延後排程，不是秒級即時保證。
- 需要人機驗證時停止重整，保留原分頁。點擴充功能的「開啟監控驗證分頁」，由你本人完成驗證。
- 真正重新讀到商品後自動恢復；不必再按恢復。一次阻擋只嘗試送出一則私人提醒，避免不確定結果重送。
- 不在前景分頁操作時重整，不觸碰被你移到其他網站的分頁。
- 總覽「停止全部」／日本拍賣停止／時段外，不派發網站讀取。擴充功能的「停止連接器」也可以單獨停止。
- 分頁被關掉但連接仍啟用時，下一次排程會重新建立。要完全停止請用控制台或擴充功能停止鈕。

安全界線：

- 只回傳商品名稱、官方商品連結、公開價格、圖片網址與庫存訊號。
- 沒有 Cookie、debugger、webRequest 權限。不匯出登入／驗證憑證，不代解 CAPTCHA，不加購物車、不下單。
- 本機配對碼是秘密；不要貼到群組。重新產生會撤銷舊配對。
- 失去連接／沒讀到商品／驗證阻擋都不是缺貨，不更新成 0 庫存，也不宣稱已恢復。
- 目前尚須實際安裝及人工驗證後確認 EDION 願意持續提供頁面；不能因測試通過就保證網站端解除限制。

Chrome API 限制：[alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms)、[scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)。
